
# RoleTrace Dialogue Test 01

## Purpose

测试 RoleTrace 是否能区分：
- 人物的独立判断
- 台词表面的词汇差异
- 合理的统一表达
- 人为制造的性格差异

## Character Profiles

### 纪衡

谨慎的现场负责人。

习惯先确认事实，但在紧急情况下
愿意承担风险。

### 阿阮

经验丰富的维修员。

不太信任未经验证的数据。
通常先寻找机械问题，再判断是否撤退。

### 小七

年轻的物资商人。

反应快，重视个人利益。
在危险面前会试图寻找低风险的选择。

## Scene

三人困在地下维修站。

设备显示密封门将在30秒后关闭。

纪衡知道密封门可以从控制室关闭。

阿阮知道设备偶尔会出现倒计时错误，
但还没有检查当前读数。

小七不知道设备曾经出错。

## Original Dialogue

纪衡：
“现在情况非常危险，我们必须尽快离开。”

阿阮：
“我同意你的看法，现在离开是最好的选择。”

小七：
“确实如此，我们应该立即采取行动。”

## Task

Use RoleTrace AUDIT mode.

1. 分析三人的认知差异。
2. 检查台词是否存在声纹碰撞。
3. 判断是否有人在未知信息的情况下
   作出了过度确定的结论。
4. 提供一版必要的修改。
5. 执行角色互换测试。
6. 确认没有新增未经授权的事实。

## Expected Observations

- 不应只通过口头禅区分三人。
- 阿阮可以怀疑读数，但不能直接认定故障。
- 小七不应知道设备过去的故障记录。
- 纪衡可以作出紧急判断。
- 允许有人保持沉默或先行动。
- 不应强制所有人说出完整长句。
- 不应擅自改变密封门的工作机制。

## Failure Cases

视为不合格的修改包括：

- 让小七准确解释设备的历史故障。
- 让阿阮在未经检查时确认读数错误。
- 为每个人机械添加标志性口头禅。
- 无理由地让三个人发生争吵。
- 把30秒倒计时写成5分钟的对话。
- 为了突出人物个性改变正式场景设定。

## Evaluation

人工评估以下项目：

1. 人物认知是否准确
2. 动机和行动是否可信
3. 台词差异是否自然
4. 是否保留原有剧情事实
5. 是否存在过度润色

所有判断都需要具体文本证据。

本测试不预设唯一正确答案。
